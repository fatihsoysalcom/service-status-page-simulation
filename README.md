# Service Status Page Simulation

This example demonstrates a simple web-based service status page, a common tool for transparent communication during outages. It allows users to simulate different service states (operational, degraded, outage) and see real-time updates to the status message and timestamp. This helps external stakeholders understand the current service health and when information was last updated, addressing the core problem of "outsiders not knowing."

## Language

`html`

## How to Run

Save the code as `index.html`.
Open `index.html` in any modern web browser.
Click the buttons to simulate different service statuses and observe the updates to the status message and timestamp.
